# Governance checklist

- [x] Synthetic data and offline execution only
- [x] Current fee schedule preferred; superseded sources filtered by default
- [x] Role/tool authorization checked before action
- [x] Retrieved content treated as untrusted data
- [x] PII redacted from answers and audit arguments
- [x] One hash-chained audit entry per integrated request
- [x] Trace spans emitted for authorization, execution and audit
- [x] Degraded response and human handover on injected outage
- [ ] Bank security and privacy approval before production
- [ ] Authenticated identity and durable human escalation integration
- [ ] Retention/access controls validated by policy owner
